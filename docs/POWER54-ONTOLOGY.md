# POWER54 — Governed Power and Influence Ontology (Draft v0.1)

Status: PROPOSAL — not an authority source. Constitutional inheritance and existing AGENT-ENTITY identity rules remain normative.

## Scope
PowerRelation describes observable relationships; AuthorityGrantRef references an independently verified mandate; StrategicPatternObservation is a falsifiable hypothesis; PowerAssessment is reproducible derived evidence. None confers permission.

## Core relationships
CONTROLS_RESOURCE, DELEGATED_BY, AUTHORIZED_FOR, DEPENDS_ON, REWARDS, SANCTIONS, INFLUENCES, AUDITED_BY, REVOCABLE_BY, AFFECTS.

## Evidence contract
Each assertion MUST carry subject and object stable AGENT-ENTITY references, evidence_refs, observed_at, source provenance, assertion_status (OBSERVED, INFERRED, DISPUTED, RETRACTED), confidence with calibration context, reviewer status, validity bounds, and invalidation conditions. Avoid psychological labels and unsupported intent claims.

## Theory references

6. Derived graph indexes are rebuildable; WikiVault retains provenance.
