# APS Candidate Priority Queue

This queue is based on the current public-repository audit. It is a standards-extraction queue, not permanent APS numbering.

## Tier A - extract first

### Governed Agent Payment
**Primary source:** AGENTROPOLIS-PAY-PROTOCOL  
**Current maturity:** C3  
Already contains a protocol specification, roles, core objects, normative rules and conformance language.

### Agent Identity / Delegation / Runtime Authority
**Primary source:** AGENTROPOLIS-SOVEREIGNTY  
**Supporting sources:** AGENTROPOLIS-ATG, AGENTROPOLIS-AGENT-MCP, HERMES-CITY  
**Current maturity:** C2  
Existing Agent DID Runtime Standard v1 separates root identity, agent identity, delegation, mandate, capability grant, execution and receipt.

### MCP Capability Authorization
**Primary source:** AGENTROPOLIS-AGENT-MCP  
**Supporting sources:** AGENTROPOLIS-ATG, HERMES-CITY  
**Current maturity:** C2  
Extract capability declaration, permission boundary, tool invocation authority and evidence semantics.

### ATG Semantic Contract
**Primary source:** AGENTROPOLIS-ATG  
**Supporting source:** AGENTROPOLIS-ONTOLOGY  
**Current maturity:** C2  
Define portable semantic profiles for identity, mandate, capability, receipt, evidence and related system objects.

### Agentropolis Core Ontology
**Primary source:** AGENTROPOLIS-ONTOLOGY  
**Current maturity:** C2  
Normalize agents, skills, memory, policies, workflows, permissions, events, routing, evidence and authority relationships.

### GTM / UGC Distribution and Attribution
**Primary source:** WIRED-CHAOS-GTM  
**Supporting implementations:** AGENTROPOLIS GTM ecosystem repositories and distribution receipt/schema work  
**Current maturity:** C2  
Target lifecycle: creator -> asset -> rights -> campaign mandate -> distribution authorization -> publication -> attribution -> performance evidence -> compensation -> receipt.

### Hermes Spawn / Runtime Handoff
**Primary source:** HERMES-CITY  
**Supporting source:** WCM-HERMES-BLUEPRINT  
**Current maturity:** C2  
Extract project spawn, runtime handoff, capability and receipt semantics.

### IP Rights / Licensing / Provenance
**Primary source:** AGENTROPOLIS-PUBLIC-IP-DISTRICT  
**Supporting sources:** AGENTROPOLIS-EPD, AGENTROPOLIS-33.3FM  
**Current maturity:** C1  
Separate creation, ownership, license, distribution authority, attribution and evidence.

All other active public repositories remain C0 until a reusable interoperability primitive is isolated. Product-specific behavior may remain a reference implementation rather than becoming its own APS.
